One line, big laugh: a deterministic Python program that writes a single original joke — a neighbor's dog, a barked reply, and an HR meeting — to `entry.txt`.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
